# 测试与质量

## 触发条件

任务涉及新增或修改测试、移动 `src/` 模块、测试执行或覆盖率时读取本技能。

## 执行规范

- 使用 `pytest`；测试目录应与 `src/` 模块路径对应，测试文件名与被测模块一致。
- 测试方法应由以 `Test` 开头的测试类包裹。
- 移动源文件时同步移动并调整对应测试文件。
- 按任务涉及的模块运行 `tests/tomorrow`、`tests/rainy` 或 `tests/fragile`；代码变更后按项目要求运行完整覆盖率检查。
- 覆盖率硬性要求为 100%（语句覆盖率与分支覆盖率均须达到 100%）；完整命令以 `CONTRIBUTING.md` 为准：不要凭空改写环境变量或路径。
- 提交前必须运行完整覆盖率检查，并确认报告中的 `TOTAL` 为 100%；任何未覆盖代码都必须通过补充有效测试解决，不得通过排除源文件、降低阈值或削弱测试绕过要求。

## 验证

记录实际执行的测试和覆盖率结果；未执行或失败时说明原因，不跳过或削弱测试。
