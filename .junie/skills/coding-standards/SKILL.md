# 编码规范

## 触发条件

任务涉及生产代码、重构、格式化、静态检查、类型标注或异常处理时读取本技能。

## 执行规范

- 遵循 `pyproject.toml` 中的 Ruff 配置，修改后运行适用的 Ruff 检查和格式化验证。
- 为所有方法和函数保留明确的类型标注。
- 抛出异常时优先使用模块内部专用异常；没有合适异常时创建模块专属异常，避免直接使用通用异常。
- 保持现有架构和局部代码风格，不为无关代码进行顺手重构。

## 验证

检查 Ruff 输出和类型标注；结合变更风险运行相关测试，并报告未执行的检查。
