# Agent 指南

## 基本边界

- 将仓库根目录作为相对路径和命令的基准；先检查现有文件、配置与架构，再决定如何修改。
- 只修改完成任务所需的文件，不重写无关内容，不凭空假设文件、命令、配置或运行结果存在。
- 遵循项目已有约定；用户要求、仓库规则和本指南发生冲突时，按更高优先级执行，并说明取舍。
- 修改后进行与变更风险相称的验证；在交付中明确说明未执行、失败或无法执行的验证。

## 按需加载

开始相关工作前，读取对应的 `.junie/skills/<skill>/SKILL.md`：

- 测试、测试移动或覆盖率：`testing-quality`。
- 代码实现、重构或质量检查：`coding-standards`。
- 配置项、设置模块或环境变量：`configuration-management`。
- README、贡献指南或其他项目文档：`documentation-maintenance`。

Skill 提供专项执行规则；`CONTRIBUTING.md` 是开发者参考文档。只加载当前任务需要的规则，避免将专项内容复制回本入口。
